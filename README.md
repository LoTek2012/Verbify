# Verbify
A web app for reviewing English irregular verbs

## Usage
Verbify runs entirely in your browser. It does not need an account, a database, or a backend; quiz answers are not saved or sent anywhere.

Start a local web server from the project root:

```sh
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). Select the first and last verbs to review, enter the base form, past simple, and past participle for each prompt, and see your mastered-verb score and percentage at the end.
